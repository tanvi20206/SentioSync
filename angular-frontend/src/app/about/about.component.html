What is SentioSync?

SentioSync is a platform that uses Natural Language Processing (NLP) and Deep Learning to analyse the sentiment and emotions behind any piece of text.

Whether it's a social media post, customer review, or any message — SentioSync can tell you if it's Positive, Negative, or Neutral, and which emotion dominates — joy, anger, fear, sadness, surprise, or disgust.

It was built using a dual backend architecture — Django handles all AI/ML processing while Node.js handles real-time WebSocket connections.
